MAVIS desktop package (Ubuntu / Zorin OS)

Build: python3 packaging/deb.py /tmp/mavis.deb --billing-url https://billing.example.com
Install: sudo apt install ./mavis.deb
Open MAVIS from the desktop menu. On first launch a terminal shows the Python
dependency installation; the dashboard then opens in your browser.
The app icon is a replaceable placeholder in packaging/icon.svg.
Set up your own Ollama, Qwen TTS, animation assets and YouTube channel.

Billing operator setup:
Deploy billing_service.app:application with a production WSGI server behind
HTTPS. Persist the SQLite database on a private writable volume. Back it up.
Set PAYPAL_MODE=sandbox, PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET,
PAYPAL_PLAN_ID, MAVIS_BILLING_PUBLIC_URL (HTTPS), and MAVIS_BILLING_DB.
Create a paid recurring plan without a free trial or setup fee. Use separate
credentials, plans, and databases for sandbox and live. Switch PAYPAL_MODE to
live only after validating your own sandbox checkout and renewals.
Add future providers in billing_service/connectors.py; each implements
checkout, status, and portal. This adapter bills on a schedule, not per video.
Keep secrets out of the desktop package. Rate-limit checkout at the proxy.

MAVIS uses a random account key stored at <workspace>/.subscription-key.
Back it up securely to keep account access across reinstalls or migration.
This build uses the key as account identity; email login/recovery is not included.
Every new production job checks Stripe through the billing service. If the
service is unreachable or the subscription is inactive, new jobs stay locked.
Existing jobs can finish and existing videos remain accessible. Without a
billing URL the package stays locked. Do not publish the unconfigured package.
Development source checkouts run without the package billing requirement.
