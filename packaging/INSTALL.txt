MAVIS for Ubuntu / Zorin OS

Install prerequisites: sudo apt install python3 python3-venv ffmpeg
Extract the archive. Open a terminal in the MAVIS folder and run:
    sh install.sh

The installer downloads Python dependencies. Launch MAVIS from the application
menu. Its dashboard opens in your browser; production runs on your computer.
For diagnostics, see ~/.local/state/mavis/launcher.log.

Set up Ollama with qwen3:4b for local script writing, and supply your own
compatible animation assets and local Qwen TTS setup. Use the dashboard setup
checks to see what's missing. YouTube authorization is needed for uploading.
No channel credentials, voice models, or customer artwork are included.
By default, the installed app keeps its data under ~/.local/share/mavis/workspace.

For the publisher: configure billing.env before running packaging/build.py.
Use a Stripe Payment Link for a recurring price and the Stripe customer portal
login link. Only public Stripe URLs belong in this file; never put secret keys
in the installer. On reinstall the existing user billing configuration is
preserved in ~/.config/mavis/billing.env. Empty links are hidden. Checkout
collects payments; this build does not require a paid subscription to run.
