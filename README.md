# TubeAssistant — English source conversion

This package converts the recovered Paul Revere pipeline source to English and separates the reusable animation and voice engines from their original character and speaker assets.

## Included changes

- English Telegram menus, help, command names, confirmations, errors, setup prompts, progress messages and AI control instructions.
- English preference names and natural-language settings: pacing, voice tone, language, clip style, thumbnail settings, preferred/excluded topics, duration and music volume.
- English documentation inside converted modules. Legacy Python module and function names remain compatible with existing integrations; they are not interface labels.
- The saved complete-cel animation renderer remains: whole-pose walking cycles, narration energy, mouth animation, action-cycle timing, captions, verification and encoding.
- The installed local Qwen voice pipeline is included: design or selected reference input, local CPU synthesis, cached WAV output, validation, retries and normalized MP3 output. Edge TTS remains an explicitly selectable alternative.
- No original mascot artwork, cel sheets, background artwork, preacher instruction, speaker reference audio, model weights, OAuth tokens or API keys are bundled. There is no automatically selected speaker.

The original Paul Revere runner and editorial behavior remain in the source. This change does not generalize channel subjects, implement a website, create a repository, or perform the upstream ownership comparison.

## Workspace and selected profiles

Use a new directory and virtual environment. This package does not install itself over the live Paul Revere pipeline or change scheduled services.

`TUBE_WORKSPACE` selects the workspace; its default is `~/.tomey-media/`. `VOICE_ENGINE_DIR` selects the installed native Qwen runtime directory containing `source/build/qwen-tts` and `models/`. Point it to the existing engine when reusing your installed runtime. The old bundled `reference.wav` is never selected implicitly.

`media-profile.json` contains the optional brand name, selected animation folder and background. `voice-profile.json` contains the selected provider and voice specification. The files in `examples/` are deliberately unfilled templates, not a supplied voice or mascot.

To select a replacement animation pack and voice:

```bash
python3 configure_media.py \
  --workspace /absolute/path/to/new-workspace \
  --assets-dir /absolute/path/to/selected-animation-pack \
  --voice-profile /absolute/path/to/selected-voice-profile.json \
  --background /absolute/path/to/selected-background.png \
  --brand "Your selected brand"
```

The command validates inputs, copies the selected assets, records their checksums and creates the two profiles. It refuses to overwrite existing profiles. It does not synthesize a voice, publish a video or touch systemd.

The animation pack retains the renderer's existing sheet formats:

| File | Format |
| --- | --- |
| `poses.png` | Three columns by two rows: idle, small talk, large talk, pointing, action start, action end |
| `walk-cycle.png` | Four columns by two rows: eight complete poses |
| `walk-cycle.json` | Eight objects containing `mouth: [x,y]` and `floor: y` in each cel's coordinates |
| `puff-cycle.png` | Three columns: the three action poses; the filename is retained for compatibility |
| `action-cycle.json` | Optional three objects with action-pose `mouth` and `floor` anchors |
| `approved-animation-sha256.json` | Selected asset checksums, generated by the configuration command |

Optional animation settings include `ground_y`, `action_start`, `moving_landscape` and `action_smoke`. Landscape drawing and smoke are off unless selected. The action beat and narration pause remain part of the retained pipeline.

For local Qwen narration, the voice profile must specify `provider: "qwen-local"`, a nonempty `reference_text`, and either a new `instruction` or an explicitly selected `reference_wav`. The model names and manifest are in `voice-runtime/`. For Edge TTS, specify `provider: "edge-tts"` and a nonempty `voice` identifier. Rate and pitch default to neutral settings.

## English commands

`/preferences`, `/setpref`, `/run`, `/publishnow`, `/queue`, `/channel`, `/schedule`, `/upcoming`, `/setpublish`, `/setvideosperday`, `/newplaylist`, `/comments`, `/memory`, `/forget`, `/confirm` and `/cancel` use English names. Other existing English commands are retained.

Preferences are written to `video-preferences.json`. When legacy keys are explicitly imported into that file, the loader converts them to English names and maps old pacing/position values. It does not silently alter the original installation's preferences.

## Validation and limits

Run `python3 -m unittest discover -s tests -v` from this source directory.

Six tests pass: English preference changes and old-key migration; explicit speaker selection; complete-cel rendering using temporary replacement artwork; configurable caption branding; narration chunk preservation; and local voice design/cache orchestration with WAV validation and real FFmpeg normalization. The expensive native speech model is simulated in that test. All delivered Python files compile.

This is a source conversion of the recovered modules and saved local voice update, not a verified export of the current laptop installation. The original recovery archive did not include the complete installed CLI/launcher or all production integration hooks. Those absent files have not been invented here. This is not yet a complete web application or a new all-in-one installer. Live native speech-model inference, full production rendering, OAuth and YouTube upload have not been tested in this environment.

Upstream notices are retained in `LICENSE.upstream`; native voice engine notices are in `voice-runtime/LICENSE-engine.txt`.
